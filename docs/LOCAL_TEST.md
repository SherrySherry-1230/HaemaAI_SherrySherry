# 해마.ai 개인 로컬 테스트

현재 목표는 M1의 생성·갱신·저장·회상 흐름을 M2 웹 콘솔에서 검증하는 것이다.
이 안내는 로컬 서버와 테스트 도구가 이미 있는 현재 개발 작업영역 기준이다.
외부 배포본이나 M1/M2 전체 기획 완료를 뜻하지 않는다.

## 실행과 접속

해마 저장소 폴더에서 다음 명령을 실행하고 터미널을 열어둔다.

```sh
npm run server:solo
```

브라우저에서 **http://127.0.0.1:7877** 을 연다. 기본 포트는 대표님이 확정한 **7877**이다.
서버를 끄려면 실행한 터미널에서 `Ctrl+C`를 누른다. 컴퓨터가 잠자거나 꺼지면 다시 실행해야 한다.

개인 테스트 기본 저장소는 `local-server/solo-test-data/🧠장기기억저장소_feat.해마🧠/`다.
처음에는 빈 쩜통이 연결되어 있고, 이후에는 같은 기억을 다시 불러온다.
기존 `local-server/haema/`의 개인 기록이나 이전 서버 설정은 자동 이관하지 않는다.

## 대표님이 확인할 순서

1. 상단 저장소 버튼이 `연결✅`인지 확인한다. 다른 저장소를 쓰려면 저장소 버튼에서 전체 경로를 입력한다.
2. API 키 버튼에서 제공자·키·모델을 설정하고 저장한다. 이때부터 실제 제공자의 사용량이 발생할 수 있다.
3. 모달을 닫고 `핑크라는 친구와 테스트카페에 다녀왔어`처럼 가상의 대화를 입력한다. Enter는 전송, Shift+Enter는 줄바꿈이다.
4. 오른쪽 쩜 목록과 왼쪽 JSON 답변 가이드에서 저장된 기억과 회상 재료를 확인한다. 해마가 호스트 대신 대화하지는 않는다.
5. 같은 대상에 관해 다시 이야기하고, 쩜의 ID가 유지되며 사실·언급 횟수가 갱신되는지 확인한다.
6. 쩜을 펼쳐 수정한 뒤 새로고침한다. 수정 내용과 기억이 유지되어야 한다.

`+ 새 쩜 만들기`와 쩜 수정은 AI 키 없이도 연결된 저장소에 저장된다.
`목록에서 숨기기`는 현재 화면만 숨기며 파일을 삭제하지 않는다. 새로고침하면 다시 보인다.
브라우저의 폴더 선택 기능은 전체 경로를 알려주지 않으므로 서버 연결에는 전체 경로 입력이 필요하다.

## 확인한 범위

- 쩜 저장소: 선택한 폴더에서 생성·수정·조회·검색·회상, `_2`처럼 새로 만든 저장소 연결, 소유자 격리.
- v4 쩜태그: `jjtags` 기준 조회·회상·고민 해결 처리.
- 대화: 정확한 이름 또는 별칭이 일치하면 기존 쩜 갱신, 확인된 ID끼리 쩜선 연결.
- AI 설정: 서버 저장 결과를 기다린 뒤 준비 상태 반영, 모달 재개방, 사용자 지정 Base URL 유지.
- 개인 테스트 서버: 자기 컴퓨터에서만 접속, 공개 화면 자산만 제공.

검증 명령:

```sh
npm test
npm run typecheck
npm run scenario
node --disable-warning=ExperimentalWarning --experimental-strip-types --test tests/local-server-smoke.test.ts
node tests/local-console-smoke.mjs
```

`npm run scenario`는 임시 저장소의 공개 예시를 사용한다. 개인 시드는 기본적으로 읽지 않는다.
HTTP·브라우저 검증은 임시 설정·기억과 로컬 가짜 AI 응답만 사용하며 실제 API 키나 외부 AI를 호출하지 않는다.
실제 제공자의 키·모델 권한·할당량과 답변 품질은 대표님의 설정으로 별도 확인한다.

2026-09-24 검증 결과: 단위·통합 테스트 52개, 시나리오 18개, HTTP 흐름 1개가 통과했고 타입 검사도 통과했다.
브라우저에서는 저장소 연결, 수동 쩜 생성·수정·새로고침 유지, API 설정 저장·전환·편집·삭제,
대화에서 쩜 생성·회상·같은 ID 갱신까지 확인했다.

## 남은 범위

- MCTS 탐색, 실제 타이핑 중 AI 분석, 전체 13개 알고리즘, 개인정보 자동 절삭·파일명 마스킹, 병합·복원, 배포 패키징은 이번 수정의 완료 항목이 아니다.
- API 프로필의 브라우저 암호화 키는 현재 세션에 의존한다. 브라우저를 완전히 닫으면 프로필 목록 복구가 제한될 수 있지만 활성 서버 설정은 유지된다.
- 현재 `server:solo`는 API 설정을 `local-server/solo-test-config/`에 저장한다. 기억 폴더는 API 키 변경과 무관하게 유지된다.
- `local-server/`, `tools/`, `tests/`, `AI/`는 기존 Git 무시 규칙을 유지하므로 해당 구현·기록은 이 컴퓨터에만 있다. 새 컴퓨터용 배포는 M3의 별도 범위다.
