# EXPECTED SCENARIO — 2·3단계 테스트 정답지
 
> 작성: 2026-09-05 (대표 원문, SherrySherry 정리). 2단계(회상)·3단계(통합)의 완료 기준은
> 이 문서의 시나리오가 **재현되는가**로 판정한다 (`docs/PLAN.md`).
> **유저는 Haema를 의식하지 않는다. 평소처럼 AI 친구와 이야기할 뿐이다.**
>
> 현재 상태(2026-09-11): 시나리오의 **회상·가이드·꼬리 확산** 파트는 2-a(회상 엔진)에서
> 결정론으로 재현된다(`tests/recall.test.ts` SCENARIOS 절). 반면 **세포 자동 생성(추출)**,
> summary 생성, mode 정교화(편들기 판정)는 2-b 영역이며, 아직 마이풉 연동이나
> 대화→추출→저장 통합 파이프라인이 완성된 상태는 아니다.
> 마이풉↔Haema 연동은 임시 웹콘솔로 먼저 검증한 뒤 정식 연동하는 순서로 진행한다.

## ■ 시나리오 01 「핑크는 누구야?」 — 세포 생성 → 통합 → 관계 형성 → 회상

1) **처음 언급**: "핑크라는 친구, 분홍색 좋아해서 별명이 핑크. 고딩 때부터. 어제도 핑크랑 술 먹고 놀았어"
   → HCell [인물: 핑크] 생성, H-tag [친구, 술자리, 분홍, 고교]
   → Haema가 이어묻기 후보 제공: "핑크랑 원래 고등학교 때부터 친구야?"

2) **며칠 뒤**: "일주일 전에 [박**]랑 술 먹은 것도 개웃겼는데"
   → 이어묻기 후보: "일주일 전이면 핑크랑 마신 거? [박**]는 누구야?" → 유저 "[박**]가 핑크야, 본명 박**"
   → **세포 통합**: 핑크 ⇄ 박** → 대표 [박**], 별칭 [핑크, 박**], 기존 기억 전부 승계

3) **관계 형성**: 반복 기록에서 요약 생성 — 박** → 오래된 친구 → 술 친구 → 가까운 사람
   (유저가 "절친"이라 말한 적 없음. **꼬리가 만든 정보**)

4) **훗날**: "이번 주말 뭐 하지" → 단서 주말→약속→친구→핑크 → 후보 반환 → AI "이번 주말엔 핑크랑 뭐 안 해?"

## ■ 시나리오 02 「좋은 기억 소환」 — H-tag 단서 회상 (이름 없이)

- 유저: "요즘 힘드네…" (핑크 언급 없음)
- 호스트가 cue [즐거움, 스트레스 해소] 요청 → Haema가 핑크 술자리 세포 + 답변 가이드 반환
- AI: "그때 핑크랑 놀아서 스트레스 풀리지 않았어? 좋은 기억 떠올려보자"
- **완료 기준: 이름 단서 없이 태그 단서만으로 재현**

---

## ■ 시나리오 03 「안** 사기꾼」 — 부정 기억 저장 + 편들기 + 위로 단서

- 유저: "안**이 월급 외에 지분 주기로 해놓고 안 줘! 완전 사기꾼!"
- Haema: HCell [인물: 안**] 생성/갱신, H-tag [회사, 배신, 분노], valence 부정 — **부정이어도 저장은 항상**
  → 꼬리 탐색: 안** 과거 긍정 기록("좋은 대표였음"), 유저 주변 긍정 인물들
  → 답변 가이드: 모드=편들기 / 허용=같이 화내기·과장 응원 / 위로 단서=[이전엔 좋은 대표였음, 좋은 사람도 많이 만남] / 금지=상대 옹호·훈계
- AI: "아 진짜 화나네? 내가 가서 때려줄게. …근데 그 사람 처음엔 괜찮은 대표였잖아. 넌 좋은 사람도 많이 만났어."

## ■ 킬러 데모 「비 오는 날의 카페」 — 감정+장소+사건이 꼬리를 문 연상

- 유저: "오늘 비 오니까 이상하게 그 카페 생각난다"
- AI: "성수에 있던 카페? 너 거기서 면접 떨어진 날 혼자 앉아 있었다고 했잖아"
- **검색이 아니라 연상임을 체감하는 순간.** 부정 세포지만 유저가 먼저 꺼냈으므로 "알아봐 주는" 용도로 제공됨
