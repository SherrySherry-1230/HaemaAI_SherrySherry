API 키 설정 · 로컬 전용 테스트 콘솔

이 콘솔은 Haema 테스트용 임시 화면입니다. 마이풉과 별개이며, 화면·스타일은 아직 다듬지 않았습니다.

1) API 키 설정

현재 활성화된 제공자·모델·키를 넣습니다. 저장하면 브라우저 로컬 저장소에 암호화해 보관합니다. 실제 암호화 방식은 아직 구현하지 않았고, 구조만 잡아 둔 상태입니다.

비워 두면 기존 기본값을 사용합니다. 지금은 환경변수(SOLAR_BASE_URL) fallback 구조를 유지합니다.
