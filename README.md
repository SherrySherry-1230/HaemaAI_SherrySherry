# 🦭 Haema — AI의 해마

> **An artificial hippocampus for AI.**
> LLM은 거대한 피질(지식)을 가졌지만 해마가 없다. Haema는 그 빈자리에 꽂히는 기억 기관이다.

**용어** — 기억의 최소 단위는 **해마세포**(코드 `HCell`), 세포 사이 연관은 **꼬리**(`Tail` — "해마가 꼬리에 꼬리를 문다"),
세포에 달린 표식은 **H-tag**(해마태그, `tags` — 긍정/중립/부정 valence도 H-tag의 한 종류), 대화가 끊길 때 던질 화제는 **이야깃거리**.

---

## 🧠 왜 만들었나

대화가 끝나면 AI는 오늘 만난 사람도, 같이 웃었던 사건도 잊는다.
"기억 데이터를 넣어줘도 안 쓰는" 문제는 저장이 아니라 **회상(꺼내 쓰는 타이밍)** 의 문제였다.

사람의 해마는 창고가 아니라 **사서**다 — 기억을 묶고, 색인을 만들고,
조각 단서 하나로 세트 전체를 떠올리게 한다. Haema는 그 일을 AI에게 해준다.

## ✨ 무엇을 하나

| | |
|---|---|
| 🔖 **해마세포** | 기억의 최소 단위. 인물·장소·사건·표현… 하나가 세포 하나 (`HCell`) |
| 🏷️ **자동 추출** | 대화에서 해마세포를 스스로 만든다. 유저가 등록하지 않는다 |
| 🔗 **꼬리** | 세포끼리 weight로 엮인다 — 해마가 꼬리에 꼬리를 문다. "권**"+"엄마" → "루*코인"이 딸려 나온다 |
| 🎯 **선별 회상** | 관련 세포만 골라 챗봇에게 넘긴다. 기본 1홉, 최대 2홉, 토큰 상한 |
| 🧬 **별칭 통합** | "핑크" = "박**"임을 알게 되면 하나로 합친다. 틀리면 되돌린다 |
| 🌙 **자동 정리** | 안 쓰는 기억은 삭제가 아니라 잠든다. 다시 언급되면 깨어난다 |
| 🤐 **환각 방지** | 기억이 없으면 빈 결과. 지어낼 재료를 주지 않는다 |

## 🧩 어떻게 쓰나

Haema는 **기억을 만들고 넘겨주는 소프트웨어**다. 말하는 건 당신의 챗봇이 한다.

### 👀 이런 식으로 움직인다

> 유저: "오늘 비 오니까 이상하게 그 카페 생각난다"
> AI: "성수에 있던 카페? 너 거기서 면접 떨어진 날 혼자 앉아 있었다고 했잖아"

감정+장소+사건이 꼬리를 문 연상 — **검색이 아니라 연상임을 체감하는 순간.**
부정 세포지만 유저가 먼저 꺼냈으므로, 챗봇은 그걸 **"알아봐 주는"** 용도로 쓴다.
